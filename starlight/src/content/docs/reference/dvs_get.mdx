## Description

Fetches the specified files from DVS storage and writes them
to their original paths in the working directory. With no `paths`
or `glob`, `dvs_get()` scopes to the working directory: it restores
the files directly under it, and `dvs_get(recursive = TRUE)` restores
every tracked file beneath it at any depth.

A working file that differs from the tracked version is replaced without
asking only when dvs itself put it there (for example after switching git
branches). Otherwise it is a conflict, handled by `on_conflict`.

## Details

In an interactive session, `dvs_get()` shows a progress bar while it
copies files. It shows none in a dry run or in a non-interactive session,
such as `Rscript`. The cli options for progress bars, such as
`cli.progress_show_after`, do not change this.






## Usage

```r
dvs_get(
  paths = character(0),
  glob = NULL,
  recursive = FALSE,
  dry_run = FALSE,
  on_conflict = NULL,
  on_error = NULL
)
```

## Value

A tibble of class `dvs_get_result` with one row per requested file
and always the same columns: `path`, `local_path`, `before` (`"absent"`,
`"current"`, `"clean"`, `"modified"`, `"unknown"`, `"not_tracked"`,
`"not_a_file"`, `"unsafe_path"`), `action` (`"restored"`, `"replaced"`,
`"unchanged"`, `"skipped"`, `"not_run"`, `"failed"`, `"would_restore"`,
`"would_replace"`), `satisfied`, `size`, `target_hash`, `local_hash`,
`stored_copy`, `code`, `message`, `hint` and `duration_ms` (the
milliseconds spent on the file, `NA` when it was never hashed or
copied). [`dvs_result_info()`](../dvs_result_info/) returns
the outcome and the policy that applied. Outside a dvs project it raises an
error. A configuration error, for example `on_conflict = "overwrite"`
in dvs.toml, raises a `dvs_config_error`.

In a dry run, `satisfied` is the prediction: `TRUE` when the file would be
at its tracked version afterwards.

In scripts and pipelines, use `on_error = "error"` (or set
`options(dvs.on_error = "error")`) so the analysis cannot continue on data
that was not updated.




## Examples

```r
# Not run:
# In a script: stop unless get did as asked
dvs_get(recursive = TRUE, on_error = "error")

# Interactively: look at what needs attention
res <- dvs_get(recursive = TRUE)
res[!res$satisfied, c("path", "code", "hint")]
dvs_get("data/derived.csv", on_conflict = "overwrite")
```
