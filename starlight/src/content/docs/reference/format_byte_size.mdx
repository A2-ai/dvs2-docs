## Description

Formats a size the way the dvs CLI prints it. The size columns of
[`dvs_add()`](../dvs_add/), [`dvs_status()`](../dvs_status/) and [`dvs_get()`](../dvs_get/) print this way in a tibble.






## Usage

```r
format_byte_size(size_bytes)
```

<td><code>size_bytes</code></td>
<td>A size in bytes: one whole number, 0 or more. `TRUE` and `FALSE` are refused.</td>
</tr>
</tbody>
</table>

## Value

A string. Below 1024 bytes it is the count with `B`, as in
`"512 B"`. From 1024 bytes up it has one decimal and the largest unit
that fits: `KB`, `MB`, `GB` or `TB`. The units are powers of 1024, so
`format_byte_size(1e6)` is `"976.6 KB"`.
